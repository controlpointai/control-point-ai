# ControlPointAI SEO Phase 2 Plan

1. Normalize the production hostname, `/index.html`, trailing slashes, internal links, and self-referencing canonicals sitewide.
2. Audit unique titles, descriptions, H1s, Open Graph data, and Twitter metadata on every indexable page.
3. Strengthen links among services, case studies, and Insights; identify orphan pages.
4. Add Organization, WebSite, Service, Case Study, and breadcrumb structured data where visible content supports it.
5. Crawl for status-code errors, redirect chains, duplicate URLs, robots/indexing problems, and sitemap exclusions.
6. Improve accessibility and performance with existing assets.
7. Review Google Search Console indexing/performance data and Ahrefs referring-domain/backlink exports.
8. Recover legitimate existing link equity before pursuing new link acquisition.
