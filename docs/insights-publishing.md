# Publishing ControlPointAI Insights

Wayne continues publishing through Decap CMS. The build creates complete static HTML pages, human-readable URLs, archive links, metadata, structured data, related links, redirects, and sitemap entries.

Automatic URL, search-title, search-description, and related-article options are recommended. Custom overrides remain available.

## Sitemap

Submit `https://controlpointai.org/sitemap.xml` once in Google Search Console. It is regenerated at every deployment, so it does not need to be resubmitted after each post or edit. Submit it again only if its URL changes or Search Console reports an error.

## Changing URLs

Published URLs should change sparingly. Git history is used to preserve prior human-readable slugs as permanent redirects; the Previous URL Slugs field covers exceptional older addresses.
